Death Craft texture assets
===========================

Place the following PNG files in this directory:

- dirt_texture.png
- stone_texture.png
- sky_texture.png
- grass_texture.png
- jump_button.png
- attack_button.png
- place_button.png

Keep these exact lowercase filenames. This directory is reserved for the
game's texture images. The PNG files are not included yet; add them when
the artwork is ready.

Recommended: use power-of-two dimensions (for example 256x256 or 512x512)
for block and sky textures. Button images should have transparent backgrounds.
